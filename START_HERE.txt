MODEL 2: FINISH THE MIDTERM RESULTS

Use your existing Python environment where CUDA worked. Do not run uv sync or
replace your working CUDA PyTorch installation with the upstream pinned version.
This branch's pyproject pins torch 2.4.1; your Windows/Python 3.14 laptop used a
newer CUDA wheel successfully, so this workflow does not install the project.

1. Extract Model2_Updated.zip into a NEW directory.
2. Keep these original archives in your Windows Downloads directory:
   CSCI-566-SBsrgnn-processed-diginetica.zip
   CSCI-566-SBsrgnn-processed-retailrocket.zip
   outputs.zip
   The script can also find your previously prepared Diginetica directory in the
   old project location. Never delete your original project or original outputs.
3. Open PowerShell in the new Model2_Updated folder containing model2_finish.py.
4. Run:

   python -m pip install matplotlib
   python model2_finish.py --device cuda

WHAT IT DOES
- Audits both datasets against the exact hashes recorded by the team's baselines.
- Repairs the misplaced RetailRocket summary ONLY in the extracted working copy,
  and only if it has exactly the manifest's expected SHA-256 hash.
- Copies the two saved best Diginetica checkpoints, without changing the originals.
- Runs preparation and neural integration checks before any real model inference.
- Re-evaluates both Diginetica checkpoints; DOES NOT retrain either one.
- Produces Recall, MRR, and NDCG at 10 and 20, plus cross-entropy loss, on clean
  and all nine frozen noisy test conditions. No evaluation noise is regenerated.
- Trains ONE new RetailRocket Model2 (fixed 50% example selection, 10% pooled
  deletion budget, training seed 2028, noise seed 2026) using latest-branch SR-GNN.
- Saves a complete training checkpoint after every epoch and automatically resumes
  it if the command is rerun. A partial epoch restarts from the previous checkpoint.
- Saves results.json and robustness_results.json in the shared team's format.
- Builds model2_results/comparison_full.csv and its JSON equivalent.

Results are single-seed. This is supervised noisy-input training, NOT contrastive
SSL. No new architecture, recency weighting, or protected final click is introduced.

REFERENCE BASELINES
The ZIP contains the team's existing SR-GNN and SASRec results for BOTH datasets.
They are included as references, with their original provenance. Their hardware
and training initialization/software differ from your old laptop run. Do not
interpret timing differences as an algorithmic speedup, or small accuracy changes
as statistically significant.

The current SR-GNN initializes the GNN parameters once before the model-wide reset;
the old branch did not. Loading your old saved state_dict preserves the old learned
weights exactly; fresh RetailRocket training uses the new branch's initialization.
CUDA training uses fused Adam to match the new baseline runner; CPU uses unfused.

For a matched RetailRocket clean-vs-noisy comparison on your laptop, run:
   python model2_finish.py --device cuda --retail-clean
This also trains a clean RetailRocket baseline on the same machine and settings.
The default command uses the team's already-published RetailRocket clean baseline
as a reference to avoid duplicating their training.

OPTIONAL STAGES
Prepare files and validate data only (no PyTorch required):
   python model2_finish.py --stage prepare
Only fill the missing Diginetica metrics:
   python model2_finish.py --stage metrics --device cuda
Only train/evaluate RetailRocket:
   python model2_finish.py --stage retail --device cuda
Rebuild the combined CSV from completed result files:
   python model2_finish.py --stage report
Plot completed Model2 and reference results:
   python plot_model2.py

If an archive is elsewhere, specify its full path:
   python model2_finish.py --device cuda --retailrocket "C:\path\retailrocket.zip"
Other path options are --diginetica and --saved-runs.

VALIDATION AND LIMITS
The preparation tests, full real-data hash/invariance audits on both datasets,
exact reproduction of the original Diginetica training-noise hash, and syntax
compilation were checked in the preparation environment. That environment lacks
PyTorch; it did NOT train RetailRocket or run the updated neural tests. The command
above performs the neural checks in your existing laptop environment first.
No missing metrics or RetailRocket Model2 accuracy values have been fabricated.

Memory: both original laptop runs recorded 226210816 bytes = 215.7314 MiB peak
PyTorch allocated training/validation GPU memory. This is not total nvidia-smi
usage, and is not the same measurement scope as all upstream memory results.
The old laptop was unplugged/using power saving during part of the work, so do not
claim that the training-time difference measures the cost of augmentation.
